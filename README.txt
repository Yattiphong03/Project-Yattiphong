สมุดโอที – รุ่นปรับปรุง v11

ไฟล์ในแพ็กเกจ
- index.html: หน้าเว็บหลัก (ต่อยอดจาก index(6).html)
- sw.js: Service Worker (ปรับ cache เป็น otbook-v11)
- manifest.webmanifest: การตั้งค่า PWA จากไฟล์ต้นฉบับ

สิ่งที่ปรับปรุง
1. ลดความหนาเส้นขอบและเงาการ์ด เพิ่มความเข้มของข้อความรองให้อ่านง่ายขึ้น
2. ปรับชื่อหัวข้อบางรายการในหน้าตั้งค่าให้อ่านง่ายขึ้น โดยไม่เปลี่ยนค่าหรือสูตรคำนวณ
3. ใช้รายละเอียดแบบพับเก็บได้ที่มีอยู่ต่อ และจัดกลุ่มเครื่องมือการเงินให้กดเปิดดูเมื่อจำเป็น
4. เพิ่มงบประมาณรายจ่ายตามหมวด เปรียบเทียบกับรายจ่ายในรอบเงินเดือนที่เลือก
5. เพิ่มเป้าหมายเงินเก็บและแถบความคืบหน้า ยอดเงินเก็บเป็นตัวติดตามเท่านั้น ไม่ถูกหักจากยอดคงเหลืออัตโนมัติ
6. เพิ่มค้นหาและตัวกรองประเภทรายการ/หมวดในรายการรับ–จ่าย
7. ปรับข้อความสถานะสำรองข้อมูลและเตือนเมื่อข้อมูลสำรองเก่าหรือยังไม่เคยสำรอง
8. เพิ่ม financePrefs ในการจัดเก็บและส่งออก JSON เพื่อให้ค่างบประมาณ/เป้าหมายติดไปกับไฟล์สำรอง

ความเข้ากันได้และข้อควรระวัง
- ข้อมูลเดิมจะถูกอ่านผ่าน normalize เดิม และเพิ่ม financePrefs เป็นฟิลด์ใหม่แบบ optional
- สูตร OT, ตัวคูณ OT, จำนวนชั่วโมงวันหยุด และรอบเงินเดือน/วันตัดรอบไม่ได้ถูกแก้
- งบประมาณใช้เทียบกับรายจ่ายในรอบเงินเดือนที่กำลังเลือก ไม่ใช่ยอดทั้งเดือนปฏิทินหากวันตัดรอบไม่ใช่วันที่ 1
- การตั้งเป้าหมายเงินเก็บไม่ได้โอนหรือหักเงินจริงจากบัญชี/ยอดคงเหลือ
- ข้อมูลยังจัดเก็บในเบราว์เซอร์ของอุปกรณ์เดิม ควรดาวน์โหลดไฟล์ JSON สำรองเก็บไว้นอกเครื่องเป็นประจำ

การตรวจสอบที่ทำ
- ตรวจไวยากรณ์ JavaScript ของสคริปต์ใน index.html ด้วย Node.js: ผ่าน
- ตรวจไวยากรณ์ sw.js ด้วย Node.js: ผ่าน
- ตรวจโครงสร้าง HTML ด้วย HTMLParser: ผ่าน
- ตรวจยืนยันค่าตัวคูณ OT และ cutoffDay เริ่มต้นใน source: พบค่าต้นฉบับเดิม
- พยายามเปิดหน้าใน Chromium headless เพื่อทดสอบ responsive แต่ browser ในสภาพแวดล้อมนี้ไม่เริ่มทำงานจนจบ จึงยังไม่ยืนยันการทดสอบ interaction จริงหรือการทดสอบบน iPhone จริง

ติดตั้ง/นำขึ้นโฮสต์
อัปโหลด index.html, sw.js และ manifest.webmanifest ไปไว้ในโฟลเดอร์เดียวกัน โดยคงชื่อไฟล์ตามนี้ เพื่อให้ service worker และ manifest อ้างอิงได้ถูกต้อง
